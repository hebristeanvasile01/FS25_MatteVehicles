# Matte Vehicles – FS25

![icon](icon_preview.png)

Say goodbye to the plastic shine. **Matte Vehicles** makes the paint of every vehicle and implement matte: no gloss, no clear coat, for a realistic, worn-in farm look.

## Features
- **No gloss**: paint smoothness is lowered and the clear coat is removed
- **Works on everything**: all vehicles and implements, including other mods
- **Glass, lights, mirrors and chrome stay reflective**
- **Runtime only**: no game files are changed
- Adjustable matte level: `SMOOTHNESS_FACTOR` in `scripts/MatteVehicles.lua` (1.0 = original, 0.0 = fully matte)

## Install
Download **FS25_MatteVehicles.zip** from the [latest release](../../releases/latest) and put it in your `mods` folder. Do not unzip it.
